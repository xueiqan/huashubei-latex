# 4 问题四：基于滚动数学启发式的多区域算—储—电协同优化模型

## 4.1 建模思路

问题四在前三问基础上进一步开放任务调度与储能运行决策，需要同时确定任务执行区域与开工时刻、储能充放电策略以及区域购售电行为。任务迁移和错峰会改变各区域 AI IT 负荷，经 PUE 转化后进一步影响新能源消纳、储能状态和电网功率交换；反过来，电价、碳强度、新能源出力及储能状态又会影响任务的时空调度。因此，任务调度与能源调节之间存在明显的双向耦合，不能简单将问题二和问题三依次串联。

本文沿用前三问已经确定的任务可行域、算力约束和储能运行机理，在统一决策空间内建立多区域算—储—电联合优化模型，其基本传递关系为

[
\boxed{
\text{任务时空调度}
\rightarrow
\text{AI IT及设施负荷}
\rightarrow
\text{新能源与储能调节}
\rightarrow
\text{区域购售电}
\rightarrow
\text{六目标综合评价}
}
]

考虑到全时域任务在“执行区域—开工时刻”上的组合规模较大，直接求解完整联合混合整数规划计算代价过高。因此采用“固定全局定标—滚动前瞻—状态感知调整—联合大邻域精修”的数学启发式，将精确整数搜索集中于关键任务邻域，在保持原模型硬约束和评价体系不变的前提下提高求解效率。

## 4.2 模型假设与时域

问题四采用第 (0\sim2399) 小时实际到达任务和实际逐时能源参数，第 (2400\sim2405) 小时不再产生新任务，仅用于结清末端弹性任务并继续进行能源结算；第 2406 小时不安排任务，仅用于储能终端状态结算。

任务一旦开始执行即不可抢占、拆分或中途迁移；开工时刻按整数小时确定，持续时间仍采用附件给出的分钟级数据，并按照任务与小时区间的实际重叠比例计算 GPU 和 AI IT 功率占用。AI IT 功率统一由 `power_mapping.xlsx` 换算，非 AI IT 负荷视为逐时已知且不可迁移。

各区域储能独立运行，同一时段不得同时充电和放电。新能源可直接供给设施负荷、用于储能充电或向电网外送，其余部分记为弃用。任务容量、网络时延、完成期限、GPU、IT及设施功率、储能运行和区域购售电边界均作为硬约束，不以罚函数允许违背。

## 4.4 新能源—储能—电网协同模型

## 4.5 六项协同评价指标

问题四要求同时权衡运行成本、碳排放、网络时延、服务质量、新能源利用率和区域峰值净购电，因此建立六项统一评价指标。

运行成本为

[
C
=

\sum_{r,t}
\left(
\pi_{rt}B_{rt}
--------------

\sigma_{rt}X_{rt}
\right),
]

碳排放为

[
E
=

\sum_{r,t}
\kappa_{rt}B_{rt}.
]

平均网络时延定义为

[
L
=

\frac{1}{N_{\rm task}}
\sum_i l_{ir_i}.
]

由于网络时延和完成期限已经作为硬约束，若直接采用任务 SLA 达标率衡量服务质量，则所有可行方案中该指标容易退化。为进一步刻画弹性任务被延迟程度，令

[
\Delta_i=\overline s_i-\underline s_i,
]

并仅对 (\Delta_i>0) 的弹性任务计算等待损失。根据 `DelaySensitivity` 的顺序关系采用等距序数量化

[
\omega_i=
\begin{cases}
3,&High,\
2,&Medium,\
1,&Low.
\end{cases}
]

定义归一化服务质量损失

[
J
=

\frac{
\displaystyle
\sum_{i\in\mathcal I_+^{flex}}
\omega_i
\dfrac{s_i-\underline s_i}{\Delta_i}
}{
\displaystyle
\sum_{i\in\mathcal I_+^{flex}}\omega_i

]

最终报告

[

[

故新能源利用率为

[

[

\max_t{\max(N_{rt},0)},

因此，模型内部统一采用

[

## 4.6 六目标固定定标与均衡优化

六项指标量纲和数量级差异明显，而题目并未规定主观权重。为避免人工赋权直接决定最终方案，沿用问题二的固定定标思想，在正式滚动求解前选取具有代表性的运行窗口，分别获得各目标的连续松弛下界 (f_m^{LB}) 和严格可行参考值 (f_m^{F})。

定义固定中心和尺度

[
a_m
===

\operatorname{mean}(f_m^{LB}),
]

[
R_m
===

\max
\left{
\operatorname{mean}
\left(
f_m^{F}-f_m^{LB}
\right),
\varepsilon_m
\right}.
]

若某指标在当前数据下几乎不发生变化，则不利用极小尺度人为放大其影响，而将其保留为评价指标。

第 (\tau) 个窗口内的标准化偏离定义为

[
d_{m,\tau}
==========

\max
\left{
0,,
\frac{\widehat f_{m,\tau}-a_m}{R_m}
\right}.
]

引入辅助变量

[
z_\tau\ge d_{m,\tau},
]

建立增广极小极大目标

[
\min Z_\tau
===========

z_\tau
+
\eta\sum_m d_{m,\tau},
\qquad
\eta=10^{-3}.
]

其中第一项压缩六项目标中最不利的标准化偏离，第二项仅在最大偏离接近时进一步改善其余指标，因此 (\eta) 只承担细化等价解的作用，而不作为主要人为权重。

## 4.7 滚动数学启发式求解

完整联合模型中，主要计算负担来自大量任务的区域—时刻组合，而储能和能源变量规模相对较小。因此，本文保留完整联合模型作为“优解”的数学定义，通过滚动数学启发式缩小每轮需要精确搜索的任务范围。

首先，以问题二得到的可行任务调度作为初始任务方案，在其形成的实际设施负荷上重新求解储能—新能源—购售电子问题，从而得到满足全部任务和能源硬约束的联合可行种子。

随后，对当前窗口中的弹性任务，根据截止期、资源需求、服务敏感度以及当前区域容量和储能状态，估计其迁移或错峰对六项标准化指标的边际影响，优先实施能够降低当前增广目标的调整。每完成一批调整后重新求解能源子问题，并按照真实 (Z_\tau) 重新评价；若联合目标没有改善，则撤销该批调整，避免边际近似误差累积。

对于由任务调整产生的局部资源冲突，仅开放瓶颈时段及其附近具有替代位置的任务重新优化。完成快速调整后，再选取对资源瓶颈、六项目标或服务质量影响较大的任务构成关键邻域 (\mathcal N_\tau)。邻域外任务固定，邻域内任务的全部合法时空位置以及当前决策区的储能、新能源和购售电变量同时开放，在原始联合约束下求解局部混合整数规划：

[
\min_{\mathcal F_\tau(\mathcal N_\tau;x^{inc})} Z_\tau.
]

只有当新方案保持全部硬约束且满足

[
Z_\tau^{new}<Z_\tau^{inc}
]

时才接受精修结果。

因此，精修阶段仍然同时优化

[
\boxed{
\text{任务调度}
+
\text{储能充放电}
+
\text{新能源分流}
+
\text{区域购售电}
}
]

而不是退化为“先调任务、再调储能”的顺序方案。

## 4.8 滚动状态传递与 SOC 可恢复约束

每轮仅提交 (H) 区内的真实任务与储能决策，前瞻区只用于估计未来资源和能源压力，不生成最终 TaskID 调度结果。窗口结束后，更新区域 SOC、历史峰值净购电、已经启动但尚未完成的任务负荷以及剩余任务集合，再进入下一轮优化。

由于滚动窗口无法在早期直接观察第 2406 小时，若只设置最终 SOC 约束，模型可能将恢复储能状态的责任不断推迟。为限制早期过度放电，在每个决策窗口末端增加终端可恢复下界：

[
S_{r,\tau+H}
\ge
\max
\left{
S_r^{\min},
,
InitialSOC_r
------------

\eta_r^cP_r^{ch,\max}
\left(2406-\tau-H\right)
\right}.
]

该约束要求当前 SOC 至少保留足够的理论恢复空间，使剩余时域仍具备恢复至初始状态的可能性。随着滚动时域逐步逼近终点，该下界自动收紧，并最终退化为

[
S_{r,2406}\ge InitialSOC_r.
]

因此，滚动求解既利用前瞻信息，又不会通过提前透支储能获取虚假短期收益。

## 4.9 顺序基准与情景分析

为衡量联合优化相对于分阶段决策的实际价值，构造顺序基准：

[
\boxed{
\text{固定问题二任务调度}
\rightarrow
\text{在其负荷上求解与问题三同构的储能—能源模型}
}
]

即先确定任务调度，再优化储能，而非直接使用问题三题面规定的固定基准负荷。联合方案与顺序方案均按照完全相同的六项指标重新计算，从而将二者差异解释为“联合决策”本身带来的收益。

针对题目要求进一步设置三类情景。

**碳约束情景。** 设原联合方案碳排放为 (E^0)，以碳排放优先求解得到低碳参考值 (E^{LC})，构造

[
E
\le
E^{cap}(\lambda)
================

E^0-\lambda
\left(
E^0-E^{LC}
\right),
\qquad
0\le\lambda\le1.
]

随 (\lambda) 增大，碳约束逐渐收紧，可比较任务迁移、储能行为与其他目标之间的变化。

**电价机制情景。** 在保持各区域平均价格水平不变的条件下，将原逐时价格替换为区域固定平均价格

[
\pi_{rt}^{fix}=\bar\pi_r,
\qquad
\sigma_{rt}^{fix}=\bar\sigma_r.
]

将该情景与原分时价格机制比较，可以识别价格时序信号对任务错峰和储能充放电的驱动作用。

**新能源波动情景。** 为避免改变新能源总供给量，仅调整其日内波动程度。设区域 (r) 第 (d) 天原有新能源非零时段的平均出力为 (\bar P_{rd}^{RE,+})，构造

[
P_{rt}^{RE}(\gamma)
===================

(1-\gamma)P_{rt}^{RE}
+
\gamma\bar P_{rd}^{RE,+},
\qquad
t\in\mathcal H_{rd}^{+},
]

并令原零出力时段仍保持为零，其中 (0\le\gamma\le1)。这样能够在保持每日新能源总量和原有出力时段不变的条件下逐步降低波动，避免人为制造夜间光伏等非物理情形。

各情景均保持任务、网络、容量和储能参数不变，并沿用基准场景的六目标定标尺度，使比较结果只反映所研究外生机制的变化。
