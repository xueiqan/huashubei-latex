# 华数杯附录与支撑材料要求核对

核对日期：2026-08-10  
依据文件：

- `2026年第七届华数杯数学建模竞赛论文格式规范与提交说明.pdf`，第1—5页；
- `华数杯大学生数学建模竞赛人工智能工具使用章程.pdf`，第1—7页。

## 赛方硬性要求

1. 论文为单独文件，格式为 PDF 或 Word，大小不超过20MB；正文从第二页开始，正文之后放参考文献和论文附录，附录页数不限。
2. 论文附录应提供参赛者实际使用的软件名称、命令和编写的全部计算机源程序；赛题提供的原始数据不必写入论文附录。
3. 支撑材料是与论文分开的附件，大小不超过20MB，使用一个 ZIP 或 RAR 压缩包提交；至少应包含论文的全部源程序，通常还应包含论文使用的非赛题原始数据、较大篇幅的中间结果图表和难以从公开渠道取得的资料。
4. 论文正文、论文附录和支撑材料均不得出现能显示答题人身份或所在学校的信息。压缩包内不得保留本机绝对路径、个人目录名、学校名称、队员姓名、学号或队号等信息。
5. 若使用 AI 工具，论文参考文献之前要有 AI 工具使用声明；论文附录还要有“AI 工具使用详情”，包括工具名称和版本、使用环节与目的、关键 Prompt 与回复摘要、采纳内容和人工修改情况。程序前还应按章程要求添加工具注释。
6. 章程明确禁止 AI 直接生成附录内容、伪造或篡改数据、替代核心方法创新以及直接生成整篇论文。因此 AI 详情只能依据队伍真实记录填写，不能用模板占位内容直接提交。

## 本次整理采取的边界

- 将当前项目中的全部24个 Python 源程序纳入支撑材料；
- 将处理后的模型输入、关键结果表和论文图纳入支撑材料；
- 不复制赛题原始 Excel 等附件，避免重复提交赛方已提供的数据；
- 不复制虚拟环境、缓存、旧结果归档、检查点和含本机绝对路径的运行日志；
- 已将参赛队提供的 DeepSeek 真实使用报告纳入附录整理；仍需核对交互日期、版本发布日期和程序注释，不把未核实内容当作最终声明；
- 源程序、处理后数据和结果均采用项目相对路径组织，便于解压后复核。

## 当前发现的交付注意事项

项目根目录 `main.py` 默认调用根目录 `preprocess.py`，但当前代码目录中没有该文件。因此支撑材料的复现说明以四个题目目录下的 `main.py` 为准；不要把 `uv run python main.py` 写成无条件可运行的总入口命令。Q2—Q4 的预处理依赖 Q1 生成的共享处理层，顺序应在说明中写清楚。
