# 第一组：Q2 多目标优化核心结果

## `q2_group1_core_results.pdf`

**性质：正文主结果图**

建议采用 **左右双子图**。

### （a）四目标全局定标偏离对比

这张不再用普通“四指标原值柱状图”，也**不建议用雷达图**。

因为成本、碳排放、网络时延和新能源指标量纲完全不同，而你的模型本身恰好已经通过

[
d_m=\frac{f_m-f_m^{LB}}{R_m}
]

完成了全局定标。因此直接画：

[
d_C,\quad d_E,\quad d_L,\quad d_Q
]

才最贴合模型。

横轴：

> 运行成本、碳排放、平均网络时延、新能源未利用率

每个指标两根柱：

> 纯算力基准 / Q2 多目标调度

纵轴：

[
\text{标准化偏离 }d_m
]

再加一条 Q2 最大偏离

[
z=\max_m d_m
]

的水平虚线。

这样读者第一眼看到的不是“四个单位完全不一样的数字”，而是：

> **Q2 到底如何在四个目标之间进行了均衡。**

这和论文里的 min-max 模型完全闭环。

数据直接来自：

* `q2_objective_summary.csv`
* `q2_global_calibration.csv`

当前模型正式输出了 `IdealLowerBound`、`NormalizationScale`、基准值以及最终四项目标值，可直接重新计算 (d_m)。

### （b）新能源利用结构变化

右图不要再重复四指标，而是解释**为什么成本和新能源利用率发生变化**。

画新能源的三项去向：

[
\text{直接消纳},\qquad
\text{新能源外送},\qquad
\text{弃新能源}.
]

比较 Q2 相对于纯算力基准的增量：

[
\Delta E_{\rm direct},
\quad
\Delta E_{\rm export},
\quad
\Delta E_{\rm curtail}.
]

采用零点居中的**增减量柱图/瀑布式表达**：

* 增加的直接消纳位于 0 线上方；
* 增加的新能源外送位于上方；
* 减少的弃新能源用“弃电减少量”统一正向表达，或者保留负号但必须标注清楚。

这里有一个非常漂亮的物理闭环：

[
\Delta E_{\rm direct}
+
\Delta E_{\rm export}
+
\Delta E_{\rm curtail}
=0,
]

因为新能源总供给没变，只是利用结构发生重新分配。

当前模型已经逐小时独立输出：

`RenewableDirectUse_MW`、`RenewableExport_MW`、`RenewableCurtailment_MW`、`OperatingCost_CNY` 等字段。

可以在右上角只放两个极简结果注释：

[
\text{净运行成本改善约 }507.34\text{ 万元}
]

[
\text{弃新能源减少约 }2.576\times10^4\text{ MWh}
]

不需要再单独画成本柱子。

### 第一组图的论文使命

这一组只回答一个问题：

[
\boxed{\text{Q2最终取得了什么多目标结果，这些收益从哪里来？}}
]

图题建议：

> **图 X  多目标调度效果及新能源利用结构变化**

正文放在 **Q2结果分析开头**。

# 第二组：任务迁移与算力负荷重分配机制

## `q2_group2_dispatch_mechanism.pdf`

**性质：正文机制解释图**

这一组只保留 **1 个高信息密度主图**。

## 6×6 跨区域迁移矩阵

纵轴：

> 源区域 A–F

横轴：

> 目标区域 A–F

矩阵元素：

[
M_{rs}
======

\sum_{i:,s_i=r,;t_i=s}
g_i d_i
]

即：

[
\boxed{\text{迁移 GPU 工作量 / GPU·h}}
]

不要只使用“迁移任务数”作为颜色，因为一个 2GPU、1小时任务与一个 100GPU、20小时任务对能源系统的意义完全不同。

### 最推荐的编码方式

**颜色深浅：**

[
M_{rs}\quad(\mathrm{GPU\cdot h})
]

**单元格内部数字：**

[
N_{rs}=\text{迁移任务数}
]

所以一个格子同时表达：

> 搬了多少个任务 + 实际搬了多大的算力工作量。

对角线 (r=s) 不建议参加色阶计算。

因为不迁移任务数量远大于跨区域迁移，若对角线参与统一色标：

[
M_{AA},M_{BB},\ldots
]

会直接把真正重要的非对角线颜色压平。

因此：

[
\boxed{\text{对角线置浅灰，仅展示“本地执行”数量；色阶仅由迁移项决定。}}
]

### 再加边缘统计，但不另算一个子图

热力图顶部增加各目标区域：

[
\text{迁入GPU工作量}
]

右侧增加各源区域：

[
\text{迁出GPU工作量}.
]

这样一张图就能够回答：

> 哪些区域在吸收算力，哪些区域在释放算力。

数据完全来自：

`q2_balanced_assignments.csv`

代码已经逐任务保存：

`SourceRegion`、`TargetRegion`、`GPU_Demand`、`Duration_h`、`Migration_GPU_Workload_GPUh`、`IsMigrated`。

### 为什么这张图比“区域 AI IT 负荷热力图”更值得正文保留

你现在最有价值的结果解释不是：

> 某时刻某区域功率是多少。

而是：

[
\boxed{\text{模型为什么会把算力从一些区域迁向另外一些区域。}}
]

这恰好对应你当前发现的调度机制：

[
D/E/F
\rightarrow
A/B/C
]

一类区域释放可外送新能源能力，另一类区域利用原本可能被弃掉的新能源。

所以这张图与第一组右图形成非常好的逻辑链：

[
\text{任务跨区域迁移}
\rightarrow
\text{算力负荷重新分布}
\rightarrow
\text{新能源利用结构改变}
\rightarrow
\text{成本下降}.
]

图题：

> **图 X  Q2任务跨区域迁移与算力工作量重分配**

放在“**调度机制分析**”段落。

## （a）数学启发式与精确 MILP 对照

这张是 Q2 算法可信度最关键的图。

使用窗口 (0\sim9) 的精确 MILP 结果作为参照，再在相同状态下运行当前数学启发式。

横轴：

[
z_\tau^{MILP}
]

纵轴：

[
z_\tau^{MH}
]

其中 MH 表示数学启发式。

画：

[
y=x
]

参考线。

理想情况所有点集中在：

[
y=x
]

附近。

### 图中不要只表达相关性

需要同时标一个小的信息框：

[
\text{平均相对偏差}
]

[
\text{最大相对偏差}
]

[
\text{中位数加速比}
]

其中

[
\delta_\tau
===========

\frac{
z_\tau^{MH}-z_\tau^{MILP}
}{
|z_\tau^{MILP}|
}.
]

加速比定义为

[
S_\tau=
\frac{T_\tau^{MILP}}
{T_\tau^{MH}}.
]

于是这一张散点图同时回答：

[
\boxed{\text{为了获得几十倍速度，究竟损失了多少方案质量？}}
]

这比单独画运行时间折线图强得多。

## （b）滚动前瞻长度稳定性

横轴只设置：

[
K=24,\quad48,\quad72\text{ h}.
]

保持：

[
H=24\text{ h}
]

不变。

不要直接把四个原始指标画在同一纵轴。

仍然利用 Q2 已有的全局定标：

[
d_C,\quad d_E,\quad d_L,\quad d_Q.
]

画四条随 (K) 变化的曲线。

纵轴：

> 标准化目标偏离 (d_m)

横轴：

> 前瞻长度 (K/\mathrm h)

重点不是要求三组值完全一样，而是判断：

> 前瞻窗口从1天改到3天时，四项目标结构是否发生剧烈变化，主要结论是否发生方向反转。

因此：

[
K=48
]

作为正文主模型，用较醒目的中心标记即可。

### 检验图不画硬约束“全零柱状图”

GPU、IT、设施功率、购电越界和能源平衡已经通过最终独立复算验证。代码本身也明确执行任务级和全时域独立复核，并输出 `GPU_Slack`、`IT_Slack_MW`、`Facility_Slack_MW`、`GridPurchaseViolation_MW`、`EnergyBalanceResidual_MW`。

| ----- | ----: |

| 能量平衡  |     0 |
| ……    |    …… |

没必要浪费一个正式图位画几根几乎为0的柱子。

## 统一绘图规范

三组图全部按**常规高水平期刊风格**做，不要大渐变背景、3D、雷达图、发光效果、复杂图标。正文所有自然语言均用中文，区域名 A–F、字段固定缩写等保留原形式；PDF 作为正式论文插图，绘图程序同时可留 PNG 预览，正式输出按 **450 dpi** 配置。图中文字、指标名称必须与论文保持一致。

正文的证据链最终非常清楚：

[
\boxed{
\underbrace{\text{图1：结果如何}}*{\text{What}}
\rightarrow
\underbrace{\text{图2：为什么得到这种结果}}*{\text{Why}}
\rightarrow
\underbrace{\text{图3：结果是否可信}}_{\text{Reliable?}}
}
]

这套比之前“雷达图 + 普通柱状图 + 负荷热力图”更适合现在已经成型的 Q2：**不重复结果数字，而是结果、机制、可信度三层各占一图。**
