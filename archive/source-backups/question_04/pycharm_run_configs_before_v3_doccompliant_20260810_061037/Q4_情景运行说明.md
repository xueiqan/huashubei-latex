# Q4情景运行配置

这些是 PyCharm 的共享运行配置。重新打开项目或在 Run Configuration 下拉列表刷新后，可直接按名称选择运行。

## 运行顺序

1. 先运行“Q4 · 01 · 低碳参考（基准种子+碳保护，自动续跑）”。它输出到`low_carbon_reference_guarded`，以已审计基准调度为可行种子，并按基准累计碳排放进行逐窗口保护。
2. 低碳参考完整结束并通过审计后，再按需选择“Q4 · 02～04 · 碳约束”。三个配置对应 `λ=0.25/0.50/1.00`。
3. “Q4 · 05 · 平价电价”以及“Q4 · 06～08 · 新能源平滑”可在基准完成后独立运行；新能源平滑的三个配置对应 `γ=0.25/0.50/1.00`。
4. 所需情景完成后，运行“Q4 · 09 · 情景比较汇总（只读）”。

## 自动保存与续跑

- 每个配置都使用固定且唯一的 `--scenario-name`，因此输出互不覆盖。
- 程序每完成一个24小时滚动窗口都会写入该情景专用检查点和进度表。
- 中断、异常退出或电脑重启后，不要删除该情景的输出目录；重新选择**同一个配置**并点击运行即可从最近检查点续跑。
- 已完整完成的情景再次运行时只会复用审计通过的结果，不会重新覆盖计算。
- 旧目录`low_carbon_reference`中的结果因最终碳排放高于基准而保留但不再使用；情景比较汇总会自动跳过它。
- 同一个情景不要同时启动两次；不同情景虽然目录隔离，仍建议一次只运行一个，以避免争用求解器和内存。

## 输出目录

所有情景均位于 `question/question_04/outputs/scenarios/<scenario-name>/matheuristic_v2/`，其中包含独立的 `tables/`、`validation/`、检查点和完成标记；基准结果仍单独位于 `outputs/matheuristic_v2/`，不会被修改。

文档未规定唯一的λ、γ取值，因此配置提供低、中、强三档：`0.25/0.50/1.00`，便于复现“随约束强度/波动程度变化”的比较。若之后增加其他取值，务必同时使用新的`--scenario-name`，避免与既有检查点签名冲突。

当前已审计基准的碳排放为0，因此新的低碳参考同样以0为上界；在这一份数据下，三个λ配置都会得到`Ecap(λ)=0`。这是碳排放非负条件下基准已达到下界的自然结果，不是运行错误；论文中应如实说明碳约束在当前数据下不再进一步收紧。

碳约束情景会自动以完成的低碳参考任务调度为可行种子，并在每个滚动窗口检查累计碳排放上界；不要改回Q2种子或手动替换该参考目录。
