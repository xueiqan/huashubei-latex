\sum_{r,s}x_{irs}=1,

实时推理是否满足

[
s_i=a_i,

G_{rt}^{AI},\qquad

F_{rt},

S_{r,t+1}

S_{rt}

最后验证：

充放电互斥、购售电边界及

# 三、检验 2：只选 2 个窗口做完整联合 MILP 对照

这是 Q4 最需要的**解质量检验**。

不再像原方案那样拿很多窗口，更不能再完整跑2406小时。

只选：

[
\boxed{2\text{个窗口}}
]

而且选择规则固定，避免挑好看的窗口。

第一个取**普通窗口**：

> 总求解时间最接近全部窗口中位数的窗口。

第二个取**困难窗口**：

> 主算法实际耗时最长的窗口。

这样一个代表正常工况，一个代表最困难工况。

对这两个窗口读取当时完全相同的：

[
SOC_{\tau},
\quad
P^{hist}_{r,\tau},
\quad
已提交任务,
\quad
剩余任务,
]

然后重新建立该窗口的**完整 H+K 联合 MILP**，即不做 LNS 邻域固定，所有本窗口合法任务变量重新开放。

但是给完整 MILP 一个硬时间：

[
\boxed{T_{ref}=300\text{ s/窗口}}
]

最多也就是：

[
2\times300=600\text{s},
]

约10分钟级，不会再拖几个小时。

### 对比指标

主要比较增广目标：

[
Z_\tau
======

z_\tau+\eta\sum_m d_{m,\tau}.
]

记正式数学启发式结果为

[
Z_\tau^{MH},
]

300秒完整 MILP 找到的最佳可行结果为

[
Z_\tau^{REF}.
]

计算

[
\delta_\tau
===========

\frac{
Z_\tau^{MH}-Z_\tau^{REF}
}{
\max(|Z_\tau^{REF}|,10^{-8})
}.
]

同时记录：

[
T_\tau^{MH},
\qquad
T_\tau^{REF}.
]

如果300秒完整 MILP已经给出有效下界 (LB_\tau)，还可以计算

[
\Gamma_\tau
===========

\frac{
Z_\tau^{MH}-LB_\tau
}{
\max(|Z_\tau^{MH}|,10^{-8})
},
]

它给出了当前启发式方案相对于理论最优值的一个保守质量界。

### 这里不要规定“5%必须通过”

Q4 与 Q2 不一样，六目标、储能和任务联合后，不适合凭空规定：

> “差5%就是好，6%就是坏”。

提示词明确要求没有题意依据的阈值不要自行编造。

正确写法是：

* 若完整 MILP 在300秒内没有找到比数学启发式更好的方案，说明当前快速方案至少具有较强竞争力；
* 若找到更优方案，则如实报告 (\delta_\tau)；
* 若困难窗口存在明显质量损失，就将最终结果严格称为**高质量可行解或条件近优解**，不写“全局近优”。

这正好与最新 Q4 的理论口径一致：联合 LNS 只保证在固定邻域外任务条件下的条件近优性，不宣称完整 Q4 全局最优。

# 四、检验 3：不要额外做灵敏度，直接吃赛题要求的情景结果

这是我认为最省计算量的一步。

题目本来就要求比较：

* 不同碳约束；
* 不同电价机制；
* 不同新能源波动；

下的策略变化。

因此这些**本来就必须跑的情景结果**，直接兼作 Q4 的机制一致性与稳定性检验，不额外再跑 (K)、(\eta)、块长等一堆模型。

另外最新 Q4 本身已经规定正式顺序基准：

[
\boxed{
Q2\text{任务调度}
\rightarrow
Q3\text{储能优化}
}
]

并与 Q4 联合优化进行同口径比较。

所以这项检验实际有两层。

### 第一层：Q4 vs Q2→Q3 顺序基准

使用同样的：

[
C,E,L,J,U,P
]

和相同固定定标尺度比较。

这里要回答的是：

> **联合开放任务和储能决策到底有没有价值？**

如果 Q4 的综合目标

[
Z^{Q4}
<
Z^{SEQ},
]

且硬约束全部满足，就说明算—储—电联合优化相较简单顺序串联产生了真实协同收益。

如果只是某几项改善、某几项恶化，也没问题，要按六目标 Pareto 权衡解释。

---

### 第二层：三个题设情景看“机制方向”是否合理

这里不要求结果数值稳定不变。

反而**场景改变以后策略就应该改变**。

检验的是方向是否与模型机制一致：

碳约束收紧时，不得出现碳预算违反，且模型应更倾向于低碳时段、低碳区域或储能低碳放电路径；

固定电价后，依赖峰谷价格进行跨时段迁移和储能套利的动力应减弱；

新能源波动降低后，储能用于平滑新能源波动的压力应相应变化，弃新能源、充放电和任务错峰策略也应出现合理调整。

这比随便做：

[
\pm5%,\pm10%
]

随机扰动强得多，因为这些情景是**赛题明确要求的真实外生变化**。

## 4.10 模型检验

问题四采用滚动数学启发式求解大规模算—储—电联合优化问题，因此模型检验重点针对**最终方案的物理可行性、快速算法的求解质量以及联合调度结论的机制一致性**，不再额外设置大量需要重复全时域求解的参数扰动实验。

亦由明细轨迹独立重新计算，而不直接采用滚动求解过程中的内部累计值。

最后，以

[
\text{Q2任务调度}\rightarrow\text{Q3储能优化}
]

构成的顺序方案作为同口径基准，检验联合开放任务与储能决策是否产生协同收益；同时直接利用题目要求的碳约束、电价机制和新能源波动情景观察调度策略变化。若各情景均保持全部硬约束可行，且任务迁移、储能运行和购售电策略随外生条件变化呈现与模型机制一致的方向，则说明模型结论具有合理的情景适应性。

\rightarrow
\text{两类代表窗口求解质量对照}
\rightarrow
\text{顺序基准与题设情景检验}
}
]

验证模型结果的可执行性、算法可信度和联合优化有效性。
